Desktop speech

Download a Whisper model for local inference on your computer. Parakeet is optional on supported NeMo setups.

Smart formats

Emails, websites, times, dates and amounts land written, not spelled out. "Five thirty pm" becomes 5:30 PM.

Personal dictionary

On desktop, add custom words and snippets in the local dashboard.

Code Mode

"Snake case user name equals five" becomes user_name = 5. Dictate code without fighting the engine.

Meeting notes

The CLI can turn a recorded WAV into timestamped text and extractive notes.

Android keyboard

Dictate on Android 12+ when a compatible offline speech service and language are installed. Android setup and APK instructions.
