# SwarScribe for VS Code

Clean raw dictation without leaving the editor. Select text you
dictated (with any speech tool), run **SwarScribe: Clean selected
dictation**, and it is replaced by the cleaned version, with Code Mode
applied automatically in Python and JavaScript files. A clipboard
variant cleans whatever you last copied.

Install: open this folder in VS Code and press F5 to try it, or package
it with `npx @vscode/vsce package` and install the .vsix. Requires the
`swarscribe` CLI on PATH. Marketplace publishing needs the publisher
account holder to submit, a one-time manual step.
