# SwarScribe for Obsidian

Dictate into your notes with any speech tool, select the raw text, run
**SwarScribe: Clean selected dictation**, and the note gets the clean
version. Uses the local `swarscribe` CLI, so everything stays on your
machine and in your vault.

Install: copy this folder into `<vault>/.obsidian/plugins/swarscribe/`
and enable it under Community plugins. Community directory submission
is a standard PR to obsidian-releases, a manual step for the maintainer.
