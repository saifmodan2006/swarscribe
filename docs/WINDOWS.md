# Windows dictation

Follow the [PowerShell quick start](../README.md#quick-start). Use 64-bit Python 3.12 for the documented setup. The first model download contacts Hugging Face. `--local-only` restricts Whisper to local files. No account is needed for the published model. Try `tiny` on a low-memory machine; use `base` as a general starting point. Native inference requires the CTranslate2 DLLs to be allowed by Windows. If Windows reports Application Control error 4551, use an approved environment or transcribe files in Linux/WSL; do not change the machine's security policy to run the app.

- **Normal** keeps the transcription close to the source and applies your dictionary and snippets. Select style **plain** to disable style transforms. **Smart** adds filler removal and formatting.
- **Code** preserves prose casing rules from being applied to code and supports spoken symbols, explicit indentation and casing commands. Inspect output before running dictated code.
- **Command** requires selected text in an editor exposing UI Automation TextPattern. It previews the replacement and checks the original selection and focus again before sending. Say “make it formal,” “make it shorter,” “convert to bullet points,” or “summarize this.” The last command is extractive. To undo a previous transformation, select its replacement in the same editor, then say “undo the last transformation.” For “fix grammar” or “rewrite professionally,” run local Ollama, download a model, then put its name in dashboard settings. These commands fail explicitly if Ollama is unavailable.
- **Meeting** stores extractive notes in history when enabled. For a retained WAV and timestamped Markdown, use the CLI `meeting-record --record`. Press Enter only after obtaining consent. Output files are created exclusively to avoid overwriting existing recordings or notes.

The tray reports its current status in the tooltip and menu. Insertion sends Unicode keyboard input without changing the clipboard. It skips password fields, selected text in ordinary dictation, changed editors and unsupported controls. “Text sent” means Windows accepted the input events; an editor can still reject them. Open the dashboard to recover the recent output if history is enabled.

If Windows detects the microphone but cannot record, check its desktop app privacy setting and try a device from `swarscribe devices`. If an application handles the default hotkey itself, choose another chord and restart the tray. The current dictation limit is three minutes; use the file-based meeting workflow for longer recordings.
