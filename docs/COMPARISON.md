# SwarScribe vs Wispr Flow

An honest comparison. Wispr Flow is a polished commercial product
with a large team, native mobile keyboards and years of tuning.
SwarScribe is an open source project built on open source models.
Here is where each one stands today.

| | Wispr Flow | SwarScribe |
| --- | --- | --- |
| Price | Free plan capped, Pro about $12 to 15 / month | Free, MIT licensed |
| Word limits | 2,000 words / week on the free desktop plan | None |
| Processing | Cloud only, audio leaves your device | Local first, fully offline mode |
| Privacy | Vendor servers, vendor policies | Nothing leaves the machine by default |
| Platforms | Mac, Windows, iPhone, Android | Desktop (Mac, Windows, Linux) plus web demo and API |
| Languages | 100+ (cloud) | 99 with Whisper locally, 25 fast-track with Parakeet |
| Smart cleanup | Yes | Yes, rule pipeline plus optional local LLM |
| Personal dictionary | Yes | Yes, plain file you own, with suggestions |
| Snippets | Yes | Yes |
| Per-app styles | Yes | Yes (email, chat, formal, document) |
| Command Mode | Pro plan | Built in, free |
| Code dictation | Basic formatting | Dedicated Code Mode: snake_case, camelCase, symbols, digits |
| Meeting notes | Separate Notetaker product | Built in Meeting Mode |
| Translation style modes | Limited | Roadmap, via local LLM pass |
| Analytics | Account dashboard | Local only: words, WPM, time saved |
| Mobile keyboards | Yes, mature | Not yet, roadmap |
| Latency polish | Excellent | Good, improving |
| Source code | Closed | Open, MIT |

## Where Wispr still wins

Mobile dictation keyboards, onboarding polish, and a hosted cloud
that just works with no model downloads. If you live on your phone,
Wispr is ahead today.

## Where SwarScribe wins

Privacy, price, no caps, Linux, code dictation, built-in command
mode and meeting notes, and a pipeline you can inspect, fork and
extend. Everything Wispr charges monthly for at the feature level,
SwarScribe treats as table stakes for open source.
