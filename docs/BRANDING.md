# SwarScribe Brand

## The name

**SwarScribe.** *Swar* (स्वर) is the Sanskrit and Hindi word for voice, sound and musical note. *Scribe* is the one who writes. Put together: the voice that writes.

It replaced the launch name FlowScribe in v0.3.0. FlowScribe turned out to be a crowded name: a Chrome extension, a Webflow SEO product, an AppSumo listing and an n8n documentation tool all use it. Exact searches for SwarScribe found no product, no app and no GitHub repository using the name, which makes it ownable: one name, one project, everywhere.

Pronunciation: *swar-scribe*. Short form: **Swar**.

## The motto

**Say it. It is written.**

Supporting line: *Speak naturally. Get finished text.* Describe privacy separately for desktop, Android, browser speech and hosted bots.

## The logo

The mark is a voice wave landing as a text cursor. Four bars in the Swar gradient rise and fall like speech, and the fifth element is an I-beam cursor in Palm Teal: the moment sound becomes writing. That single idea is the whole product.

Files:
- `assets/logo.svg` - the app icon, wave on Ink
- `assets/logo-horizontal.svg` - icon plus wordmark, for light surfaces
- `assets/logo-mono.svg` - one-colour mark, for print and watermarks
- `assets/banner.svg` - the wide GitHub and social banner

Rules: do not stretch the mark, do not recolour the wave, keep clear space around it of at least one bar width, and use the mono version when colour is not available.

## Colours

| Name | Hex | Used for |
| --- | --- | --- |
| Ink | `#0E1116` | Backgrounds, the icon tile, headings |
| Paper | `#FAF5EC` | Light surfaces, text on Ink |
| Swar Coral | `#FF5A36` | Primary brand colour, the wave start, calls to action |
| Marigold | `#FFB43A` | The wave end, highlights, gradients with Coral |
| Palm Teal | `#0FA38C` | The cursor, privacy and offline signals, success states |
| Slate | `#A7B0BE` | Secondary text on Ink |

The signature gradient runs Swar Coral to Marigold, warm like a voice, deliberately unlike the blue and purple gradient nearly every AI tool uses. Palm Teal is the trust colour: wherever SwarScribe says *offline*, *private* or *done*, it says it in Teal.

## Voice of the brand

Plain, warm, honest about limits. Short sentences. No hype words, no fake metrics, no em dashes. SwarScribe talks the way its own cleanup writes.
